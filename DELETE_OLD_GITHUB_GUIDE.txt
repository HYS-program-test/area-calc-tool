請不要直接把原 Repository 清空後再慢慢上傳。

最安全方式：
1. 先下載這個壓縮檔。
2. 建立一個全新的 GitHub Repository，例如：
   area-calc-clean
3. 將本壓縮檔完整內容上傳。
4. 部署並確認沙盒模擬模式可運作。
5. 再測試 OPEN API。
6. 新 Repository 確認正常後，舊 Repository 才封存或刪除。
